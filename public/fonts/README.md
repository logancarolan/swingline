# Custom Fonts

Place the following font files in this directory:

- `Georgia.ttf` — Used for the TOC period date
- `NeueHaasGrotesk-Bold.ttf` — Used for the TOC title and column headers

If the font files are not present, the app will fall back to standard PDF fonts
(TimesRoman for Georgia, HelveticaBold for Neue Haas Grotesk).
